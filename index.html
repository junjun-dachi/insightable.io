After you download

Start using Insightable in a few simple steps.

1. Unzip the package

Extract the downloaded archive into a folder on your computer. The app bundle includes everything needed to run.

2. Launch the app

On macOS, run ./start.sh from the extracted folder. On Windows, double-click start.cmd or run it in Command Prompt.

3. Open the app

Your browser should open automatically at http://localhost:3000. If it does not, open that address manually.

First launch: the app will create its data, config, and log folders automatically, copy the example settings, and generate a local encryption key.

To stop it later: run ./stop.sh on macOS or stop.cmd on Windows.
